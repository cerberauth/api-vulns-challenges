# JWT Not Verified

This challenge demonstrates a JWT implementation that does not verify the signature.

## How to run it

```bash
go run main.go
```

## Modes

The server supports two modes, toggled with the `--vulnerable` flag on the `serve` command (defaults to `true`):

```bash
# vulnerable: the token signature is never checked
go run main.go serve --vulnerable=true

# fixed: the token signature is verified against the server's public key
go run main.go serve --vulnerable=false
```
